# Bild- och animationsfiler

Lägg dessa filer här (de följer inte med i koden):

- `level-complete.gif`: animationen när en lektion är klar. Saknas den visas Milo i stället.
- `level-complete-poster.jpg`: stillbild som visas när användaren har valt minskad rörelse eller pausar.

Använd bara material som du har rätt att använda.
